# 📘 Kumbh360 User App — Feature Documentation

---

## 🏠 Overview

**Kumbh360** is a **super app for Kumbh Mela pilgrims** powered by AI (KumbhDoot), designed to provide:

- Safe navigation 🧭
- Group coordination 👥
- Emergency support 🆘
- Seamless bookings 🏨
- Spiritual experience 🧘

---

- Voice-first assistant (multi-language)
